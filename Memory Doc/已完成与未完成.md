# 已完成与未完成清单

> 最后更新: 2026-06-01

---

## ✅ 已完成

### 产品定义
| 项目 | 说明 |
|------|------|
| 愿景文档 | Deepwell 愿景：AI 回音壁情感记录平台 |
| 核心特色 | 单对话 / 超长上下文 / 非评判回音 / 隐私优先 / 社交同步 |
| 目标用户 | 三类人群：高敏感、高表达欲、内敛型 |
| 技术栈选定 | Flutter + Go + SQLite + OpenAI + llama.cpp |

### Flutter App
| 项目 | 文件 | 说明 |
|------|------|------|
| App 入口 | `app/lib/main.dart` | Material 3，Provider 状态管理 |
| 主题配置 | `app/lib/main.dart` | 浅色/深色主题，NotoSansSC 字体 |
| Conversation 模型 | `app/lib/models/conversation.dart` | id / userId / createdAt / updatedAt |
| Message 模型 | `app/lib/models/message.dart` | id / role / content / timestamp / emotionData |
| User 模型 | `app/lib/models/user.dart` | id / displayName |
| 入口页面 | `app/lib/screens/entry_screen.dart` | Deepwell 品牌展示 + 开始记录按钮 |
| 聊天页面 | `app/lib/screens/chat_screen.dart` | 消息列表 + 输入框 + 发送按钮 |
| AI Service | `app/lib/services/ai_service.dart` | 调用云端 API，含回音壁 System Prompt |
| 加密 Service | `app/lib/services/encryption_service.dart` | AES-CBC 加密骨架 |
| 存储 Service | `app/lib/services/storage_service.dart` | SQLite，users/conversations/messages 三表 |
| Emotion Picker | `app/lib/widgets/emotion_picker.dart` | 情绪选择组件（需确认是否已实现） |
| Message Bubble | `app/lib/widgets/message_bubble.dart` | 聊天气泡组件（需确认是否已实现） |
| pubspec.yaml | `app/pubspec.yaml` | 依赖声明（sqflite, cryptography, etc.） |
