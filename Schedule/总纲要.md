# Deepwell 开发总纲要

> 最后更新: 2026-06-01

---

## 项目愿景

一个人人都可以使用的情绪记录平台。用户通过与 AI 回音壁的长期单对话，倾诉情绪、记录生活，AI 以理解、陪伴、非评判的方式给予反馈。

## 核心特色

1. **单对话模型** — 每个用户只有一个对话，所有情绪记录都在一条时间线上
2. **超长上下文理解** — AI 记住你是谁、你经历过什么、你的语言习惯
3. **AI 回音壁** — 不评判、不指责、不贴标签，像一面温柔的回音壁
4. **隐私优先** — 数据本地加密存储，开发者不可查看用户数据
5. **社交同步** — 可选择分享到朋友圈/小红书

## 技术栈

| 层级 | 技术 | 用途 |
|------|------|------|
| 移动端 | Flutter (Dart) | iOS + Android 跨平台 |
| 后端 | Go | API 服务、AI 调度、同步 |
| 本地数据库 | SQLite + SQLCipher | 加密存储用户数据 |
| AI 云端 | OpenAI / Claude API | 复杂语义理解与情感分析 |
| AI 本地 | llama.cpp (GGUF) | 简单回应本地推理 |
| 长上下文 | 对话摘要 + 向量检索 | 突破 token 限制 |

## 目标用户

| 类型 | 特征 | 需求 |
|------|------|------|
| 高敏感人群 | 生活中遭遇情绪起伏，压抑已久 | 释放和倾诉 |
| 高表达欲人群 | 习惯分享日常，乐于记录 | 分享每一次快乐和感受 |
| 内敛型人群 | 现实中不善于表达 | 引导进行线上记录 |

## 六阶段总览

```
Month 1-2:  Phase 1  项目基建 + Prompt 工程
Month 3-4:  Phase 2  核心 MVP（单对话 + 加密 + 云端 AI）
Month 5-6:  Phase 3  AI 回音壁核心（长上下文 + 情绪感知 + 个性化）
Month 7-8:  Phase 4  本地模型 + 隐私加固
Month 9:    Phase 5  社交同步功能
Month 10+:  Phase 6  内测、迭代、上架
```

## 团队分工

| 角色 | 人数 | 职责 |
|------|------|------|
| Flutter 开发者 | 1-2 | App UI、本地存储、加密、AI 客户端 |
| Go 后端开发者 | 1 | API 服务、AI 调度、同步功能 |
| AI/ML 工程师 | 1 | Prompt 工程、本地模型调优、长上下文方案 |
| 产品/设计 | 1 | UI/UX 设计、用户测试、文档维护 |

## 关键里程碑

| 里程碑 | 预期时间 | 交付物 |
|--------|----------|--------|
| M1: 项目骨架就绪 | Month 1 | Flutter 可编译 + Go 后端可运行 |

| M3: AI 回音壁完整 | Month 6 | AI 能记住用户、识别情绪、模仿语气 |

## 注意事项

1. 加密必须从第一天做起，不可后期补救
2. 单对话模型是核心差异，所有设计围绕此展开
3. AI 回音壁的人格一致性比功能丰富更重要
4. 优先保障三类目标用户的核心体验
5. 所有代码开源，接受社区审计
