#### 2.4 云端 AI 集成
- [ ] Flutter AI Service 完整实现（非骨架）

## Phase 3: AI 回音壁核心（Month 5-6）

### 目标
实现超长上下文理解 + 情绪感知 + 个性化回音。

### 任务清单

#### 3.1 长上下文压缩
- [ ] 对话摘要算法设计
- [ ] 阶段性摘要生成（每 N 条消息）
- [ ] 摘要注入 System Prompt
- [ ] 摘要的摘要（多层压缩）

#### 3.2 向量记忆检索
- [ ] Embedding 模型选型（本地/云端）
- [ ] 消息向量化存储
- [ ] 语义搜索：AI 可引用历史消息
- [ ] 相关性排序

#### 3.3 语气模仿
- [ ] 用户语言特征提取（句式长度/用词偏好）
- [ ] 语气特征向量生成
- [ ] 动态 tone profile 注入 Prompt
- [ ] A/B 测试：通用回应 vs 个性化回应

#### 3.4 情绪波动检测
- [ ] 实时情感分析集成
- [ ] 情绪变化趋势记录
- [ ] 异常情绪预警（持续低落等）
- [ ] 回应策略自动调整

#### 3.5 记忆锚点
- [ ] 用户可标记消息为"重要"
- [ ] 锚点存储与检索
- [ ] AI 在合适时机主动引用锚点
- [ ] 锚点回顾功能

#### 3.6 个性化 Prompt
- [ ] 每个用户独立的 Prompt 模板
- [ ] 动态注入用户画像
- [ ] Prompt 版本管理

### 验收标准
- [ ] AI 能引用用户 1 个月前的对话内容
- [ ] AI 回应风格接近用户自身语言习惯
- [ ] 情绪检测准确率 > 80%
- [ ] 用户可标记/回顾重要记忆
